# Little Sugar Tot Photography

A 30-page website for Kay's newborn, maternity, sitter, cake smash and family photography studio in Victoria, Australia.

It's a single `index.html` with hash routing (e.g. `#newborn`, `#pricing`, `#contact`), so it runs on any static host, including GitHub Pages.
